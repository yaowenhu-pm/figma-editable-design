# 用 Codex 写 Figma 设计稿

将用户需求写成 Figma 中可编辑的 Frame、文字、组件和布局，并按反馈修改。交付实际设计节点的链接与预览。

## 输入与范围

从当前请求取得目标 Figma 文件或节点、要做的页面、主要用户与任务、参考和本轮范围。只澄清会改变设计或写入对象的缺口；尺寸、留白等常规细节可采用合理默认值并说明。

用户只想先看一张时，完成一张核心页面供其审阅；用户已要求完整多页面时，按已授权范围完成。修改已有稿时，先读取对应页面及节点，保留未要求改动的内容。不要顺带做前端开发、发布产品或更改文件分享权限。

## 连接与能力检查

1. 查看本会话实际可调用的工具，区分读取、写入、创建文件和导出能力。工具名字带 Figma 或 MCP 不代表能够写稿。
2. 已连接的官方 Figma 插件若提供 `use_figma`，优先复用；调用前按工具要求读取对应的 `figma-use` Skill 和当前工具文档。需要新建文件时另读该工具要求的创建文件 Skill。不要将工具内部代码协议与其他 MCP 混用。
3. 用户指定 Grab 路线，或没有可用写入通路时，读取 [Figma 接入说明](references/figma-connection.md)。其中含当前使用过的项目 `grab/cursor-talk-to-figma-mcp`、Codex 注册模板与连接验证。需要安装或修改配置时，先确认该操作包含在用户请求中；已有授权不重复询问。
4. 写入前以只读请求核对目标文件、当前页面或选择节点。Grab 路线应在正确文件运行插件、加入本次 channel，再获取文档信息。不同文件或重新运行插件后重新核对；旧 channel 不作为长期配置。

没有账号授权、文件编辑权限或可调用写入工具时，说明当前缺少哪一步及用户最小操作。继续准备不依赖连接的布局与文案，不把本地 HTML、图片或脚本当作已写入 Figma。Skill 本身不包含账号、令牌或连接权限。

## 先确定用户怎么完成事情

围绕本轮核心任务，用几句话确定入口、操作对象、主要动作、结果出现的位置和下一步。将高频且必要的动作做到“一眼可见，一键可达”，常规配置给出足够好的默认值。

设计时据实际产品取舍：

- 第一眼有明确重点和主动作；减少重复入口、解释性文字、深层容器与同屏按钮。
- 图标保留必要的识别作用，按钮短而清楚；不默认加入 emoji。
- 阅读区、对话输入和辅助面板不重叠；需要收起时使用直接的收起按钮。
- 让用户知道正在操作哪个项目、对话、材料或结果，以及动作是否已完成。
- 需要演示状态时与主要稿放在同一文件中；静态设计稿不宣称已经实现真实交互或后台能力。

用户有品牌、参考稿或设计系统时先读取并延续有效约束；用户要求重新设计时，不强套旧布局。

## 写成可编辑设计稿

新稿默认在目标文件内增加名称清楚的 Frame 或页面，避开已有内容；在原稿上修改按用户指定节点进行。记录本轮根节点 ID，便于继续改稿。

使用实际可调用的工具与 schema 建立结构。优先原生 Frame、文字、矢量图标和组件；合适时用 Auto Layout、约束和可复用组件。素材可以作为图片导入，但不要把整屏扁平图片作为可编辑界面交付。

官方路线按 Plugin API 和该工具的执行约定工作，加载所用字体后写文字。Grab 路线按工具列表和参数 schema 使用 `create_frame`、`create_text`、布局与样式操作；不要假设它也支持任意 Plugin API。对缺少的能力说明限制，并选择仍能满足本轮要求的结构。

按布局分批写入，检查文字是否完整、层级是否合理、图标和按钮是否一致。不要把本机路径、上一次 channel、旧节点 ID 或私人材料固化为通用配置。

## 回读、检查与继续改稿

写入后回读根节点和关键子节点，取得截图或导出 PNG 并实际查看。检查文本裁切、重叠、边界溢出、阅读宽度、主次动作和层级。发现问题时先修复，再重新检查改动区域。

调用超时或结果不确定时先回读节点，判断已经写入的部分；不要盲目重复整批创建。连接中断时说明已完成和待完成的部分，保留可继续使用的节点信息。

交付时给出 Figma 文件／节点链接、预览、主要设计决定，以及静态稿或工具能力的实际限制。只有写入与回读成功才说稿件已完成。后续反馈直接在已核对的节点上继续修改，不无故另建一套稿。

## 调用例子

```text
使用 $figma-editable-design。目标文件：<Figma 链接>。
帮我画一张 <页面>，用户是 <人群>，主要完成 <任务>。
参考与限制：<品牌／参考链接／布局要求>。先完成这一张并给我节点链接与预览。
```

```text
使用 $figma-editable-design。修改这个节点：<Figma 节点链接>。
把右侧改成可收起的聊天区，输入框固定在底部，去掉重复按钮。
保留其余内容，完成后检查是否重叠或溢出。
```
